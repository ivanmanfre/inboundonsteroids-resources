Finish this (your homework)

None of this is required. It's just the best way to learn. Try it when you have a minute:

  • Set up your CLAUDE.md — type /init and it writes a short note about your business and how you work. Claude reads it every session, so you never re-explain yourself. The highest-value five minutes you'll spend.
  • Plan a project first — use plan mode or the brainstorming skill to map out something small, like a lead magnet or a simple page. Tighten the plan, then tell it to build.
  • Try /deep-research — ask it a real question, and it looks things up and comes back with a short report.
  • Use it on real work — pick an actual task you're doing this week and ask it to help. See how far it gets.

A few tricks (things you picked up)

  • Tell it to think harder — for a tough job, say "think hard." For quick stuff, leave it normal. Saves time and money.
  • Make it prove it — you can't read the code, so say "test it and show me what it'll do" before you trust it. That's how you check its work.
  • Don't chase every new tool — when you see a new AI thing, just ask Claude "is this better than what I already have?" and let it tell you.
  • Summarize anything long — paste a video link or a long document and ask for the three-sentence version.
  • Want to keep up? Two channels worth following — Nate Herk and Simon Scrapes, both strong on n8n and AI automation.

Handy commands (keep these nearby)

  • Plan mode (press Shift+Tab) — make it plan before it builds. Use it for anything bigger than a quick ask.
  • "think hard" — add it to a tough request and it reasons more before answering.
  • /deep-research — research a question and get a short report back.
  • /clear — wipe the slate when you start a new task, so it stays focused.
  • /memory — see and edit what it remembers about you and your business.
  • Esc — stop it mid-action if it's heading the wrong way.
  • /init — writes your CLAUDE.md so it remembers your business and how you work.
  • @filename — point it at a specific file instead of describing it.
  • /help — list everything it can do.

Take it with you (back it up + set up the Dell)

The idea: finish your setup on your main laptop, back the whole thing up to your own private repo, then pull it down on the Dell. You just tell Claude to do each part.

Step 1 · On your main laptop — finish and save
  • Finish the installs — tell Claude: "finish installing my skills and test that superpowers works."
  • Save your keys — tell Claude: "save my n8n and Pipedrive API keys in memory," then paste them in.
Step 2 · On your main laptop — back it up to your own private repo Tell Claude:
"Create a new private GitHub repo called derek-private-swppp and push my whole project folder to it, including the keys."
When it asks, make sure it's set to Private.
Step 3 · On the Dell — pull it all down
  • Install VS Code (code.visualstudio.com), add the Claude Code extension, and sign in.
  • Connect GitHub when it asks.
  • Tell Claude: "Clone my derek-private-swppp repo and set it up here."
Everything comes back — your skills, your setup, and your keys. Ready to work.
