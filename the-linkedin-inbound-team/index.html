How to use it

You need a Claude account and a place to keep the folder

There is no install, no key, no signup inside the pack. Download it, unzip it, then work down the steps below.

A

Download the pack and unzip it

Start here. The zip carries all thirty agent folders, their fixtures, and the manifest. Unzip it wherever you keep documents, then follow the folder steps below.

Download the full pack
Zip · 30 agent folders · 167 files

Once it is unzipped you have everything. The rest of this page is about running one of the thirty, and nothing below needs another download.

B

Running an agent in claude.ai

The browser path
  1. Sign in at claude.ai.
  2. Create a Project and give it the pack's name. In the project knowledge panel, upload the SKILL.md of the one agent you want to run.
  3. If Projects are not available on your plan, skip step 2: open a new chat and paste the whole SKILL.md file into the message box instead.
  4. Under it, paste your own input, the draft or the thread or the list, and send.
The Claude Code path
  1. Drop the pack folder inside the project folder you already work in.
  2. Ask for the agent by name in the session: run the gate reply writer on this, then paste your input.
  3. Claude Code opens the SKILL.md from disk itself, so nothing needs pasting twice.

One agent per conversation. Two SKILL.md files loaded at once and the second set of rules argues with the first, which shows up as an answer in neither format.

E

When an agent refuses

Sooner or later one of these will decline to answer you. That is the pack working. Each agent is written to stop rather than invent the thing you did not give it, and to say which thing that was. A refusal is a short instruction, and the run it blocks is the one that would have put a made-up detail into your own words.

THE ANSWERS ARE NOT IN THE INPUT
A detail supplied here would be one I made up, printed in your voice, in a post
with your name on it. Answer the questions from memory and paste the draft again.
verbatim from content-02-detail-finder, Refusal 3

The other shape is a bracket in the middle of an otherwise finished answer. The agent writes everything it can and marks the gap where a value should sit, with the value named:

"Hey [NEEDS: the commenter's first name], here's the Shift Handover
Checklist: example.site/handover. That's everything, no follow-up
needed from you."

That is what capture-05-gate-reply-writer prints when the comment carries no first name. The message is still usable, and the one word it could not know is sitting in brackets waiting for you rather than filled with a guess.

F

Start with the fixtures

Every agent folder carries a fixtures folder holding at least one practice input. Run an agent on its own fixture first: you get a full output on material you did not have to prepare, and you see the shape before your own draft is in the chat.

content/content-02-detail-finder/fixtures/draft-mixed-claims.md    a draft with claims and accounts mixed
capture/capture-05-gate-reply-writer/fixtures/no-link-yet.md      the input that fires the refusal
convert/convert-03-inbound-reply-writer/fixtures/inbound-reply-thanks-only.md

Several fixtures exist to make an agent refuse. Those are worth running twice: once to read the refusal, once with the missing field added, so you know what each agent asks for before you need it.

Questions

Before you open the folder

Is it really free?

Yes. Download it above and the folder is yours to keep. There is nothing to buy inside it and no account to make beyond the Claude account you run it in.

Do I need to know how to code?

No. Every agent is a text file of plain English: what to paste, what it does with it, what it will not do. You open a chat, paste, and read the answer.

What if an output looks wrong?

Run it again with more input. These agents read only what you paste into the chat, so a thin answer usually means a thin paste: the whole draft rather than the paragraph, both sides of the thread rather than the last message.

Can I change one?

Open its SKILL.md and edit it. Keep the refusal sections if you want the same behaviour, since those are the lines that stop an agent from filling a gap with something plausible.
