# Starter commands

Generic, business-agnostic versions of the stochastic multi-agent commands.
Drop the `.claude/commands/` folder into any project (or your home `~/.claude/`)
and they become slash commands: /stochastic-decision, /stochastic-research,
/stochastic-audit, /stochastic-red-team.

They read YOUR CLAUDE.md for context, so they adapt to whatever stack you run.
